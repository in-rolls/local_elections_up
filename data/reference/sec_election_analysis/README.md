# SEC election-analysis index

[index.html](index.html) is the UP State Election Commission's index of
statistical reports (https://sec.up.nic.in/site/electionanalysis.aspx), saved on
8 Sep 2026 while searching for early GP-head records. It lists aggregate
reports, not named GPs. Its URL, sha256 and fetch time are in
[fetch_log.csv](fetch_log.csv); it was moved here byte-identical from
[in-rolls/local_elections](https://github.com/in-rolls/local_elections).
