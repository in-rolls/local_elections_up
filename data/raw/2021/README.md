# UP 2021 GP-head candidate input

`gram_panchayat_pradhan_candidates.csv.gz` preserves the original 373,096-row candidate CSV byte-for-byte after decompression. It replaces the unpublished 115.9 MB local file as the central adapter's reproducible input. The gzip file is 14.3 MB and is stored in Git.

`source_manifest.json` records both compressed and original hashes. The legacy scrape's acquisition URL and retrieval time were not recorded; neither is reconstructed here. Candidate winner markers are retained as source assertions, including the documented conflicting contest.
