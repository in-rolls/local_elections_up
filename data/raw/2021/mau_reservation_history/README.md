# Mau gram pradhan reservation history, 1995-2021

Nine PDFs, one per block of Mau district, linked from the GRAM PRADHAN column of
the district's page "PANCHAYAT ELECTION 2021 : 1995-2015 RESERVATIONS DETAILS"
([index.html](index.html), saved from
https://mau.nic.in/en/panchayat-election-2021-1995-2015-reservations-details/).
Each lists GPs with a reservation code for 1995, 2000, 2005, 2010, 2015 and,
partly filled, 2021. They sit under `2021/` because the district published them
for the 2021 reservation round.

[fetch_log.csv](fetch_log.csv) gives each file's URL, referring page, sha256,
size and fetch time (8 Sep 2026). The files were fetched for
[in-rolls/local_elections](https://github.com/in-rolls/local_elections) and
moved here byte-identical; `copied_from` names the path and commit they came
from. Nothing in the build reads them yet. The page review is in
[reference/mau_reservation_history_review](../../../reference/mau_reservation_history_review/README.md).
